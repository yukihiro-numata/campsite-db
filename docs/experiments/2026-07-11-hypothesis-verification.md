# 裏取りログ: 「中立性の堀」と「モバイル操作性ペイン」の検証

実施日: 2026-07-11
目的: 勝ち筋の中核だった 2 つの仮説を、確証バイアスを排して裏取りする
(支持・反証の両方を探索)。

## 制約

本環境は WebFetch が egress ポリシー/bot ブロックで多くのホスト 403。
値は WebSearch のスニペット由来が中心で、レビュー星分布や一次本文は一部
未確認。確度はその分割り引く。

---

## 仮説①: 送客・掲載課金で稼ぐから、ネガ実測を構造化公開できない

前提 X(各社は施設課金/送客で稼ぐ)と 因果 Y(だからネガを構造化できない)に
分解して検証。

- **X = 成立(高確度)**: なっぷ(R.project)は予約売上の 5〜7% を送客手数料。
  hinata(vivit)は OTA 型送客。キャンプイズム(live for)は掲載課金/定額。
  掲載施設＝課金顧客は事実。
- **Y = 普遍法則としては棄却/弱い**:
  - **Hipcamp(米)**: ホストから 10〜15% の予約手数料を取る送客モデルなのに
    👍😐👎 の構造化評価＋騒音・清潔さのネガを公開。→ 因果を直接反証。
  - **なっぷ自身**が自然/立地/サービス/設備/管理/周辺環境の多軸星評価＋
    低評価口コミを掲載。
  - 抑制の直接証跡は、なっぷのガイドライン一例("掲載写真と実物が違う"苦情の
    排除)程度で弱い。食べログ事件は一審で優越的地位濫用を認定も二審で逆転=
    傍証として両論。じゃらん/楽天も施設はネガ口コミを自由に消せない(削除成功は
    体感 2〜3 割)=Y を弱める傍証。
- **生き残る事実**: 「静かさ/混雑/電波/トイレ汚れ 等のネガ方向の実測メトリクスを
  比較可能な独立軸として持つ社が国内に無い」ことは事実(空白は本物)。ただし
  その原因が収益構造とは証明できず(製品設計/UGC 主観性/実測コストの可能性)。

**判定**: 条件付き支持だが、当初の「資本で潰せない堀」は過大。中立性は
"堀"ではなく実行・focus 上の"優位"に格下げ(concept.md 2.5 節 / D8 に反映)。

**前向きな副産物**: The Dyrt・マンションノート(レビュー対象が非課金)は
「構造化ネガ比較は商業的に成立」の実例で、非施設課金方針(D8/7 節)と方向一致。

---

## 仮説②: モバイル操作性がペインになっている

- 操作性ペインは実在(特になっぷアプリの地図が広げられない・詳細から戻れない・
  お気に入り一覧 UI)だが**小さい**。「使いにくい」の声の主流は操作性ではなく
  予約取得難・料金・情報鮮度(体感 操作性 2〜3 割 vs 他 7〜8 割)。
- 反証が強い: hinata/sotoshiru は既に「使いやすい」と好評で**衛生要因化**。
  ユーザーは Googleマップ＋Instagram＋なっぷ併用で操作性の悪さを既に回避。
  「選び方」記事の決め手に検索 UI は登場しない。
- 追加確認: なっぷ・hinata・sotoshiru はいずれも **iOS/Android ネイティブ
  アプリを保有**(「アプリ空白」は無い)。

**判定**: 条件付き支持(弱め)/差別化としては副次的。モバイル UX は主軸から
降格し、衛生要因＋「独自軸(程度・実測・中立)とセットのくさび」に位置づけ
(concept.md 4 節 / D9 / 8 節に反映)。ネイティブアプリは作らない
(コスパ・SEO 非対応・アプリ枠は既に埋まり衛生要因)。
