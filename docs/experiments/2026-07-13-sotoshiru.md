# 競合調査: ソトシル(sotoshiru)

実施日: 2026-07-13
目的: 新規リスクだった「ソトシル(スペースキー運営)が未調査」を解消。
我々の勝ち筋(程度・実測を比較軸として構造化 × 中立)にどれだけ近いかを見る。

## 制約

WebFetch は sotoshiru.com が DNS 解決失敗、他も多くが 403。値は WebSearch の
スニペットと公開情報(PR TIMES 等)由来。個別スポットページの実 UI は未確認。

## 分かったこと

- **正体**: 株式会社スペースキー(CAMP HACK / なっぷ 等も運営)のアウトドア情報
  まとめアプリ + 写真 SNS。7 ジャンル、提携メディア 150+、2017 年開始。
  キャンプ場 MAP 検索(なっぷ提携、4,000 件+)は後付け機能。
- **程度・実測の構造化比較は無い**: MAP 検索の絞り込みは 価格 / 施設タイプ /
  ロケーション / 設備の有無 / アクティビティ / 周辺施設 =「有無・種類・エリア・
  価格」止まり。トイレのきれいさ・地面の硬さ・静かさ・混雑度を独立した軸で
  絞り込み・並べ替え・比較する機能は確認できず。
- **UGC は写真投稿(Instagram 型「スタイル投稿」)**。多軸★の構造化レビュー
  ではなく、程度情報は写真・文章に埋もれる。
- **収益は 広告 / 送客 / EC / B2B(メーカー課金)**。姉妹サービスなっぷは予約
  送客(施設が顧客)。エコシステム全体として施設・メーカーから収益を得ており、
  中立を掲げにくい。
- **警戒材料**: なっぷが 6 項目の満足度★(自然/立地/サービス/設備/管理/
  周辺環境)を持つ。ただし主観の総合満足であり、中立・実測の程度軸でも
  絞り込み比較でもない。

## 判定

現状 **hinata 同型**で、我々の空白(程度・実測の構造化比較 × 中立)は埋まって
いない。脅威は限定的。ただしスペースキーは規模・データ・メディアを持ち、
程度・実測の比較に本気で乗り出せば最速で追随しうる大手。中立性(施設から
課金しない)は彼らが構造的に取りにくく、我々の差別化余地として残る。
