# 実証ログ: AI web 集約による 1 件シードの実効性

実施日: 2026-07-11
目的: 「コールドスタート / AI シードの実効性」論点を実地で検証。AI による web
集約で 1 件のキャンプ場情報をどこまで構造化して埋められるか、出典が付くか、
無名サイトで何が起きるかを見る。

## 方法

- 対象 2 件を対比: 人気サイト(ブログ・口コミ多数)と無名サイト(web 上の言及が
  ほぼ無い小規模施設)。都心近郊のエリアで実施。具体施設名は伏せる。
- 各項目を「基本情報(当たり前品質)」と「差別化・実測 6 軸」に分け、値・出典URL・
  確認日・確信度・種別(客観/主観/実測)を 1 項目ずつ記録。

### 環境制約

本実行環境は WebFetch が egress ポリシーで全ホスト 403 になり、ページ本文を
取得できず、値は WebSearch のスニペット由来。確認日(更新日)や緯度経度が
取れず、今回は本文フェッチなしの下限値。本番のフェッチ可能な経路ではより埋まる。

## 結果サマリ

| | 人気サイト | 無名サイト |
|---|---|---|
| 基本情報 | 10/10 | 約 4.5/10 |
| 差別化 6 軸 | 5.5/6 | 実質 0/6(所要時間のみ) |
| 出典URL | 100% | 埋まった項目には付くが項目自体が乏しい |
| 主観軸の質 | 複数ソース一致で暫定値に使える | 入力ソース 0 件で生成不能 |

- 人気サイトで埋まらなかったのは実寸(区画割なし非公表)と地面の水はけ(低確信)。
  地面の硬さはソース間で矛盾があり「レンジ + 場所注記」で持つべき実例。
- 無名サイトは、名称・住所・電話・大まかな営業期間(行政・地図・電話帳インフラ
  由来)は埋まるが、料金・予約・IN/OUT・公式URL(運用情報)と体験 6 軸は全滅。
  例外は所要時間(座標から演繹)。訪問者の一次記述が 0 件だと体験軸は原理的に空。

## 結論(concept.md 6 節に反映済み)

1. 埋まり方は web 露出量で層ごとに断絶: レジストリ層(無名でも埋まる)/運用情報層
   (公式サイト有無で明暗)/体験層=差別化軸(UGC ゼロで全滅)。例外は所要時間。
2. AI 集約は「公開済み情報の再集約」で、無から一次観測は生めない。無名施設の
   差別化軸は電話取材・現地訪問という非 Web 入力が必須。
3. AI シードは有効(下限値として心強い): 悪条件でも人気サイトは基本 10/10・
   6 軸 5.5/6。
4. 設計含意: 出典種別・確認日を項目ごとに保持し空欄は「未確認」表示 / 主観軸は
   レンジ + 出典 + 場所注記 / 本文フェッチ可能なクロール経路が要る。

## 次アクション
