# コンセプトドキュメント

## 1. 目的

### 主目的

既存サービスでは不十分な点やできないことを補い、キャンプ場を簡単かつ便利に
探せるようにする。

### 副目的

1. **ポートフォリオとして公開する。** あわせて、少ない手間で持続的に開発できる
   構成を目指す。
2. **使いやすく、モダンなデザインにする。** 既存サービスの UI/UX に感じている
   使いづらさを解消する。

## 2. 対象ユーザー

キャンプ初心者〜中級者。自分自身も使う人として想定する。

## 3. 解決したい課題

キャンプ場選びで比べたい「行ってみないと分からない情報」は 2 つに分かれる。

- **有るか・どんな種類か(以下「有無・種類」)**: 例: トイレは有るか/水洗か、
  地面は砂利か芝か、オートサイトか、近くにコンビニがあるか。
- **どれくらいか(以下「程度・実測」)**: 例: トイレのきれいさ、地面の硬さ
  (ペグの刺さりやすさ)、静かさ、混み具合、区画の広さ(㎡)。

既存サービスは「有無・種類」までで、「程度・実測」を比べられるサービスは無い。
そのため「ブログや YouTube を調べて回る」のが選び方の定番になっており、地面・
騒音・トイレ・広さの失敗談も数多く見つかる。

| サービス | 主な用途 | 絞り込める情報 |
|---|---|---|
| なっぷ | 予約 + 検索(最大級) | エリア/料金/予約可否/サイトタイプ/電源/風呂/ペット/様式トイレ。広さは「100㎡以上」かどうかのみ |
| hinata スポット | 検索(メディア起点) | 上記に加え地面の種類/24時間管理/近隣コンビニ・スーパー/車乗り入れ/穴場 |
| ソトシル | 記事のまとめ + 写真投稿 | 価格/施設タイプ/設備の有無/アクティビティ/周辺施設 |
| Google マップ | 地図 + 口コミ | 構造化されていない。混み具合は口コミ件数から推測するしかない |

## 4. 提供する価値

「程度・実測」を比べられる形にまとめ、行く前に比べて選べるようにする。これで
キャンプ場探しを簡単かつ便利にする。

### 既存サービスから学んだ方針

| 既存サービスでの問題 | 方針 |
|---|---|
| 1 つの軸だけ(トイレだけ・動画だけ)では候補を絞れない | 複数の軸で横断比較できるようにする |
| 他人のブログへのリンク集では価値が薄い | 自分でデータを持つ |
| 情報はすぐ古くなる(トイレ・地面・電波は変わりやすい) | 各データに最終確認日を持ち、鮮度を保つ |
| 件数が少ないと「載っていない」が増え、使われない | エリアを絞り、その中はもれなく載せる |
| 主観の星評価だけでは比べにくい | 出典のある事実と、決まった手順で計算した値で持つ |
| 良い点しか分からない | 悪い点も含めて比べられるようにする |
