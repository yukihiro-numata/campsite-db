# 画面のルール

画面(`src/app/`)の見た目を作る・直すときのルール。

- 色は `src/app/globals.css` の `@theme` に定義した名前(`primary`、`muted` など)を使う。
  色コードや Tailwind の標準色(`gray-600` など)を直接書かない。新しい色が要るときは、
  使い方の名前を付けて `@theme` に足す。
- 文字は端末に入っているフォントを使い、Web フォント(`next/font` など)を読み込まない。
  日本語の Web フォントは重く、読み込みの途中で文字が切り替わるため。
- 余白・角丸・大きさは 4px の倍数にする(Tailwind の目盛りに .5 を付けない、`[18px]` のように
  数字を直接書かない)。文字の大きさは Tailwind の段階(`text-xs` 〜 `text-2xl`)から選ぶ。
  線の太さは除く。
