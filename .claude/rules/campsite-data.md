# キャンプ場データの集め方ルール

`src/data/` のキャンプ場データを調べて埋めるときのルール。

## 1. 「不明」と「未調査」を分ける

| 状態 | 意味 | 書き方 |
|---|---|---|
| 不明 | 調べたが、出典に書かれていなかった | `notStated(調べたページ)` |
| 未調査 | まだ調べていない | `unchecked` |

- 調べたページに書かれていなければ、迷わず「不明」にする。推測で埋めるより不明の方がよい。
- 「未調査」は、まだ手を付けていない値にだけ使う。

## 2. 出典の選び方

- 公式サイトを優先する。予約サイトは、公式に書かれていないときだけ使う。
- 公式と予約サイトの値が食い違うときは公式を採り、食い違いは PR 本文に書く。
- 設備・料金・規約・サイト紹介など、常設のページに書かれた内容で埋める。お知らせの
  休止情報やキャンペーンなど、一時的な情報は使わない。
- 一時的な事情を注記で補わない。値が変わるたびに追いかける必要が出るため。

## 3. 書かれていることだけで埋める

- 書かれていない値を、ほかの記述から推し量らない。
  - 例: 公式が電源付きのサイトにだけ「AC電源付」と書いていても、ほかのサイトを
    「電源なし」にしない。電源なしと書かれていなければ「不明」。
  - 例: 夜間の連絡先や受付時間から、夜に管理する人がいるかを決めない。
- サイトの種類の一部の区画にだけあると書かれている設備(電源など)は「ある」にする。
- レンタルは、何か 1 つでも借りられると書かれていれば「ある」にする。
- 区画サイトかフリーサイトかは、サイト名ではなく説明文で決める
  (例:「ドッグフリーサイト」はノーリードの意味で、区画サイト)。

## 4. 入れるサイト・キャンプ場の値

- サイトの種類はテントを張るサイトだけにする(コテージ・キャビン・デイキャンプ専用は
  入れない)。
- 公式ページで非表示になっているサイトは入れない。
- 座標は次の順で取る。上で取れないときだけ次に進む。
  1. 公式のアクセスページの地図に埋め込まれた座標(Google マップの `!2d経度!3d緯度` など)
  2. 予約サイトのページに書かれた座標。公式の地図がない、キャンプ場以外(牧場の本体など)
     を指す、座標が入っていない(住所の文字列だけ)ときに使う
  3. 公式の住所から、国土地理院の住所検索 API
     (`https://msearch.gsi.go.jp/address-search/AddressSearch?q=住所`)で求めた座標。
     出典の種類は計算(`calculated`)にし、`note` に手順を書く
- 静粛時間は、始まりの時刻だけが書かれていれば始まりだけを入れる(終わりは推し量らない)。
- グループ利用の可・条件付き・不可は `GroupPolicy` のコメントの区切りに従う。
- 所要時間・標高・距離は計算スクリプト(`pnpm calc`、`scripts/calc/`)で出す(手で調べない)。
