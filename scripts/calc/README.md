# 計算して埋める値のスクリプト(暫定)

キャンプ場データの「こちらで計算」した値(`travelSource` / `distanceSource`)を出すスクリプト。
データを集めるスクリプトを作るまでの暫定版で、main には入れない。

```sh
pip install mapbox-vector-tile
python3 travel.py <緯度> <経度>    # 東京駅からの所要時間(分)
python3 distance.py <緯度> <経度>  # 高速道路・国道・鉄道までの直線距離(m、1,500m 超は null)
```

- 所要時間: OSRM 公開サーバーの車の経路。渋滞なし。分に四捨五入
- 距離: 国土地理院ベクトルタイル(experimental_bvmap、z16)の road(rdCtg 0=国道、3=高速)と
  railway(ftCode 8201)。座標から線分までの最短距離を、座標のまわりを平面に近似して計算。m に四捨五入
- どちらもデータが更新されるため、日が違うと値が変わることがある。値には調べた日を付ける

長瀞(1 件目)で null / 494 / 338 と 85 分になることを確かめた。
